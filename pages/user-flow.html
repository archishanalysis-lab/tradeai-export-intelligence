How TradeAI Works End-to-End

Most users start on a public page, register or login, reach a role-based dashboard, then use reports, marketplace, Copilot, saved items, inquiries or billing features.

1. Public entry

Landing, countries, corridors, marketplace previews, pricing and report page.

2. Register or login

User selects role, accepts terms/privacy, receives JWT-backed session.

3. Role dashboard

Exporter, importer, explorer, consultant, SME or admin workspace opens.

4. Use tools

Reports, Copilot, marketplace, products, buyers, inquiries, saved items.

5. Backend response

Express controllers read/write MongoDB and return JSON to the frontend.

Role-Wise User Flows

TradeAI supports public visitors plus registered explorer, exporter, importer, consultant, SME and admin roles.

Guest / Public Visitor

Working Demo Data

Can browse country, corridor, marketplace, pricing and report pages without login.

  • Entry: `index.html`, countries, corridors, reports, pricing.
  • CTA: register, request walkthrough, explore countries.
  • Value: understand TradeAI before creating an account.

Registered Explorer

Working Backend Connected

Uses the unified dashboard for buyer discovery, market analysis, HS codes, reports and saved items.

  • Dashboard: `dashboard.html#overview`.
  • APIs: reports, billing, buyers, saved items.
  • Value: one guided workspace for trade exploration.

Exporter

Working Backend Connected Demo Data

Moves from product and HS code to target countries, buyer discovery, reports and inquiries.

  • Dashboard: `export-dash.html`.
  • Uses products, buyers, inquiries, uploads, reports, Copilot.
  • Value: structured export opportunity workflow.

Importer

Working Backend Connected Demo Data

Searches suppliers, products and companies, saves items and sends inquiries where available.

  • Dashboard: `importer-dashboard.html`.
  • Uses marketplace, saved items, inquiries and Copilot.

SME / Small Business

Working Demo Data

Explores export readiness, target markets, reports and Copilot guidance from the explorer workspace.

  • Dashboard: explorer dashboard path.

Consultant / Advisor

Working Future Ready

Uses analytics, reports, marketplace research and Copilot to support client advisory work.

  • Dashboard: `analytics-dashboard.html`.

Admin

Working Backend Connected

Reviews platform activity, users, KYC, buyers, products, inquiries, reports and requests.

Registration, Login and Protected Pages

Registration and login are connected to the backend. Protected pages redirect users to login when the token is missing or expired.

Registration

Collects name, email, company, role, password, confirm password and terms/privacy agreement.

POST /api/auth/register backend/controllers/authController.js Models: User, Organization, CompanyProfile, Subscription

Login and Token

Stores the JWT session in browser storage and sends it as a Bearer token on API requests.

POST /api/auth/login Storage: tradeai_token, tradeai_user, tradeai_logged_in Redirect: role-based dashboard path in js/auth.js

Technical Data Flow

The same pattern powers most product screens.

Frontend page -> js/config.js chooses API base URL -> js/api.js attaches JSON headers and Authorization token -> feature API helper calls /api route -> backend/server.js mounts route -> middleware validates auth and request data -> controller runs business logic -> service calls AI, uploads, trade data or matching if needed -> Mongoose model reads/writes MongoDB -> JSON response returns to frontend -> page script renders success, empty, fallback or error state

Known Limitations and Future Enhancements

These notes keep the project honest for reviewers and collaborators.

Known limitations

  • Some dashboards and marketplace views show sample data when live records are empty.
  • Razorpay requires production credentials and final plan rules before full payment launch.
  • Consultant and SME roles currently reuse broader dashboard tools.
  • Copilot quality depends on backend availability and OpenAI configuration.

Future enhancements

  • More role-specific onboarding and dashboard modules.
  • Stronger marketplace verification and review workflows.
  • Plan-based buyer unlocks, report quotas and analytics limits.
  • Admin audit logs, deeper moderation and production auth hardening.
