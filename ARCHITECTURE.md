# TradeAI Architecture

## Tech Stack

### Frontend

- HTML
- CSS
- JavaScript
- Static pages
- Vercel deployment

### Backend

- Node.js
- Express.js
- MongoDB
- JWT authentication
- Render/Railway deployment

### External Services

- MongoDB Atlas
- Cloudinary
- Razorpay scaffold
- OpenAI / AI Copilot fallback
- UN Comtrade API fallback/demo data
- Future Redis/Upstash queue
